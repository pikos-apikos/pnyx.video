# pnyx.video

Production workspace for **a documentary from a reality that could exist**.

The first film follows an ordinary community trying to rebuild a neglected playground without making anyone invisible. PNyX is not explained as a technical system; it is revealed through how people listen, disagree, decide, execute, return, and learn.

## Workflow

This repository uses **Joey Workflow — Cinematic Wayfinder**:

- GitHub issues hold the canonical production map and decision tickets.
- Repository files hold canon, prompts, manifests, provenance, and approved assets.
- Only explicitly approved assets become references for downstream production.
- One creative frontier ticket is worked at a time.
- Invalid, rejected, and superseded outputs remain traceable but are never reused as canon.

See [`docs/WORKFLOW.md`](docs/WORKFLOW.md) once the bootstrap branch is merged.
