# Contributing to pnyx.video

This repository is a production workspace, not an open-ended prompt playground. Contributions are most useful when they improve one specific artifact or resolve one explicit production question.

## Start from the map

1. Read the [canonical production map](https://github.com/pikos-apikos/pnyx.video/issues/1).
2. Check the current frontier and existing issues.
3. Do not begin downstream work while its upstream character, prop, environment or scene reference is still unresolved.
4. Prefer one coherent contribution over a bundle of unrelated generated material.

## Useful contributions

- focused review of the treatment, continuity or visual language;
- provenance or licensing corrections;
- accessibility, representation or documentary-ethics review;
- deterministic asset preparation requested by an open ticket;
- comparison of production tools against explicit acceptance criteria;
- a prototype produced for a named prototype ticket.

## Please do not

- generate new named characters without an open character ticket;
- reinterpret an unapproved candidate as canon;
- submit infographics or dossier cards where a clean reference image was requested;
- silently replace approved identity, wardrobe, prop or location details;
- present synthetic material as evidence of a real civic event;
- upload third-party material without recording its source and usage rights.

## AI-assisted work

AI assistance is allowed, but disclose:

- the model and tool used;
- what it produced;
- the references and prompts used where relevant;
- what you personally reviewed;
- known uncertainty or remaining defects.

AI output is not independent evidence, professional attestation or proof of factual accuracy.

## Asset provenance

Every production asset should eventually record:

- asset ID and status;
- source or parent asset IDs;
- tool and model version;
- complete prompt where applicable;
- generation ID and seed when available;
- transformations and edit history;
- SHA-256 hash;
- human approver;
- source license or consent basis.

See [`provenance/AI_DISCLOSURE.md`](provenance/AI_DISCLOSURE.md) and [`assets/manifest.yaml`](assets/manifest.yaml).

## Creative approval

Creative candidates become canon only after explicit human approval. A pull request may prepare or preserve candidates, but it must not silently promote them.
