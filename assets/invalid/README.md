- the production-package infographic generated instead of a face lock;
- Nikos candidates generated after the known character frontier was lost;
- Sofia generated instead of Anna;
- adult red-haired Anna generated instead of the defined 15-year-old Anna;
- Panagiotis generated during the same state-loss loop.

Invalid means wrong artifact or wrong identity, not merely an unselected creative alternative.
